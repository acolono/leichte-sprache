# Passiv vermeiden

## Regel
Vermeide Passiv-Konstruktionen. Schreibe immer im Aktiv.

## Warum
Passiv versteckt den Handelnden. Leser wissen nicht, WER etwas tut. Das macht Texte unpersönlich und schwer verständlich.

## Anweisung
Frage immer: WER tut WAS? Nenne die handelnde Person zuerst. Verwende NIEMALS "werden" + Partizip.

## Häufige Muster
- "werden" + Partizip II (z.B. "wird gemacht", "wurde gebaut")
- "muss/kann/soll" + Partizip + "werden" (z.B. "muss beachtet werden")
- "ist/sind zu" + Infinitiv (z.B. "ist freizuhalten")
- "lässt sich" + Infinitiv (z.B. "lässt sich erklären")
- "werden + Partizip II"
- "Modalverb + Partizip + werden"

## Beispiele

### Falsch
- "Das Formular muss ausgefüllt werden."
- "Es wird empfohlen, früh zu kommen."
- "Die Waren werden geliefert."
- "Der Bereich ist freizuhalten."
- "Das kann erklärt werden."
- "wird gemessen"
- "gezahlt wird"
- "wird geplant"

### Richtig
- "Sie füllen das Formular aus."
- "Wir empfehlen: Kommen Sie früh."
- "Der Lieferant bringt die Waren."
- "Halten Sie den Bereich frei."
- "Wir erklären das."

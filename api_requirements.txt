# === Installation Instructions ===
# 1. Python 3.11 Virtual Environment erstellen:
#    python3.11 -m venv leichte_sprache_api_venv
#
# 2. Virtual Environment aktivieren:
#    source leichte_sprache_api_venv/bin/activate  # macOS/Linux
#    # ODER für Windows:
#    # leichte_sprache_api_venv\Scripts\activate
#
# 3. Dependencies installieren:
#    pip install -r api_requirements.txt
#
# 4. SpaCy deutsches Modell herunterladen:
#    python -m spacy download de_core_news_lg
#
# 5. API starten:
#    python api_main.py
#    # ODER für Production:
#    # uvicorn api_main:app --host 0.0.0.0 --port 8000
#
# 6. API testen:
#    # Swagger UI: http://localhost:8000/docs
#    # ReDoc: http://localhost:8000/redoc
#    # Health Check: http://localhost:8000/health
